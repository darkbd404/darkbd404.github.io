# Munafa Hisab PWA v4

GitHub Pages + Android PWA.

## V4 changes
- High-resolution PNG report generated locally, no html2canvas dependency.
- Report includes start date, maturity date, period, rate, principal, gross profit, deduction, net profit and total payable.
- Full Theme Studio: Ocean, Emerald, Royal, Sunset.
- Theme changes apply across page, cards, buttons, result, tabs and developer panel.
- Animated gradient/glow effects.
- Top segmented navigation for Calculator, Themes and Developer.
- App logo in the header.
- Developer photo URL, phone, email, Facebook and Messenger.
- Principal presets from 50,000 through 1 crore.
- Maturity date and all date fields update live when month/start date changes.
- PWA offline cache and versioned service worker.

Upload all files to the GitHub Pages repository root.
